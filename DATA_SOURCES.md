# Data sources

This repository contains the source snapshots and cleaned analysis data used for the 2024-25 Oklahoma City Thunder player-value analysis.

- Basketball-Reference, 2024-25 Oklahoma City Thunder roster and statistics: https://www.basketball-reference.com/teams/OKC/2025.html
- Basketball-Reference, 2024-25 NBA season summary: https://www.basketball-reference.com/leagues/NBA_2025.html
- Salary Sport, Oklahoma City Thunder 2024 payroll archive: https://salarysport.com/basketball/nba/oklahoma-city-thunder/2024/
- Additional salary reconciliation sources are recorded in `documentation/DATA_AUDIT.md` and `documentation/salary_decisions_2024_25.csv`.


## Public-repository format

The salary workbook sheets used by the analysis are stored here as CSV exports (`okc_2024_25_salaries.csv` and `okc_2024_25_additional_contracts.csv`). Basketball-Reference tables are stored as CSV snapshots of the downloaded 2024-25 tables used in the analysis.
